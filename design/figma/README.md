# DX_carry Figma import

`DX_carry_app_mockup.svg` is a Figma-importable draft board for the Android screens.

How to use:

1. Open Figma.
2. Drag `DX_carry_app_mockup.svg` onto the Figma canvas.
3. Select the imported groups named `Home`, `Call`, `Items`, `Routine`, and `Settings`.
4. Adjust colors, spacing, typography, and component shapes in Figma.
5. Send the updated design back or export measurements so the Android XML can be updated.

Android XML cannot be opened by Figma directly, so this SVG is the editable bridge file.
